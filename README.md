# 🚦 TrafficFlow AI

A web-based intelligent traffic management system that performs data-driven lane planning and adaptive traffic optimization using Artificial Intelligence.

## 📌 Project Title

**Data-Driven Lane Planning and Adaptive Traffic Optimization using Artificial Intelligence**

## 🛠️ Tech Stack

- React (Vite)
- Flask
- PostgreSQL
- OpenCV
- YOLO
- Bootstrap

## ✨ Features

- Vehicle Detection
- Lane Detection
- Traffic Density Analysis
- Adaptive Signal Optimization
- Interactive Dashboard
- Reports and Analytics
